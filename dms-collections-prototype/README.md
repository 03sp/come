# DMS Collections — animated prototype (Gen Z themes)
Single-file prototype: open `index.html` in a browser (works offline except Google Fonts).
Flow: logo intro -> login -> customer search -> LAN picker -> overview / timeline / rule configuration (gear theme).
Themes: Pop, Midnight, Soda, Neon (switcher at top).
Source (plain JS, no framework): shell.css, shell.js, data.js, screens/*.js. Rebuild with `python3 build.py` (outputs dist/index.html).
Brief for rebuilding in another tool: see BRIEF.md and BRD-guidance.md.
